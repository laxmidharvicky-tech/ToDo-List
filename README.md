# 📝 Todo List App

A simple and beginner-friendly **Todo List web application** built using **HTML, CSS, and JavaScript**.

This project allows users to add tasks to a list and remove tasks when they are completed or no longer needed.

## ✨ Features

* ➕ Add new tasks
* 🗑️ Remove tasks

* 🎨 Simple and clean user interface
* 📱 Responsive design
* ⚡ Fast and lightweight
* 🌐 Runs directly in the browser

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/laxmidharvicky-tech/ToDo-List.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Run the application

Open `index.html` in your browser or use the **Live Server** extension in VS Code.
